## Purpose

为怀旧排位服提供一个无需登录、按格式隔离的浏览器排行榜页面，使玩家可以直观看到当前月赛季榜和跨月份总榜，并在空榜、错误或排位关闭时得到明确反馈。

## ADDED Requirements

### Requirement: 公开参数化排行榜页面

服务器必须（SHALL）在排位开启时公开无需登录即可访问的 `GET /leaderboards/:format` 页面。当前有效页面必须（SHALL）包括 `/leaderboards/1103` 与 `/leaderboards/1109`，页面必须（MUST）显示实际格式且不得混入或回退到其他格式。

#### Scenario: 访问 1103 排行榜页面

- **WHEN** 排位开启且用户访问 `/leaderboards/1103`
- **THEN** 服务器返回可在浏览器使用的 1103 排行榜页面，并且页面后续请求只查询 1103 排行榜 API

#### Scenario: 无需登录访问页面

- **WHEN** 未携带账号、PIN、Cookie 或管理凭据的用户访问有效格式页面
- **THEN** 服务器正常返回排行榜页面，不要求认证，也不在页面中暴露账号 ID、PIN、密码或录像数据

#### Scenario: 访问未启用格式页面

- **WHEN** 用户访问未在固定格式注册表中启用的 `/leaderboards/:format`
- **THEN** 服务器返回明确的页面不存在响应，不回退到 1103、1109 或跨格式页面

#### Scenario: 排位关闭时访问页面

- **WHEN** `RANK_ENABLED=false` 且用户访问任一排行榜页面
- **THEN** 服务器返回明确的排位功能不可用响应，不渲染可能被误认为实时排行榜的空页面

### Requirement: 页面提供当前月赛季榜和历史总榜切换

页面必须（MUST）提供月赛季榜与历史总榜两个视图。首次加载必须（MUST）查询北京时间当前 `YYYY-MM` 的月赛季榜；用户切换视图或月份时，页面必须（MUST）使用当前页面格式调用既有 `/api/leaderboards/:format`，且只展示最后一次选择对应的结果。

#### Scenario: 首次加载默认当前月榜

- **WHEN** 用户在任意本地时区打开有效格式页面
- **THEN** 页面按 `Asia/Shanghai` 计算当前 `YYYY-MM`，请求 `scope=season&season=<当前月份>` 并把该月份显示为当前选择

#### Scenario: 切换到历史总榜

- **WHEN** 用户在 1109 页面选择总榜
- **THEN** 页面请求 `/api/leaderboards/1109?scope=overall` 并显示跨月份汇总结果，不携带赛季参数

#### Scenario: 查询其他月份

- **WHEN** 用户选择一个合法的其他 `YYYY-MM` 月份
- **THEN** 页面请求当前格式的对应月赛季榜，并显示所选月份，不回退到当前月或总榜

#### Scenario: 快速连续切换查询条件

- **WHEN** 用户在前一次请求返回前再次切换格式内的榜单视图或月份
- **THEN** 页面最终只展示最后一次选择对应的数据，较早响应不得覆盖当前选择

### Requirement: 页面清晰展示排行榜数据与状态

排行榜页面必须（MUST）以表格展示 API 返回的排名、昵称、积分、胜场和负场，并明确区分加载中、空榜和请求失败状态。昵称必须（MUST）作为纯文本展示，不得解释为 HTML。

#### Scenario: 展示有数据的排行榜

- **WHEN** 当前查询成功返回一个或多个排行项
- **THEN** 页面按 API 返回顺序逐行显示 `rank`、`name`、`points`、`wins` 和 `losses`，包括负积分和并列排序后的稳定名次

#### Scenario: 展示空月份

- **WHEN** 当前查询成功但排行榜数组为空
- **THEN** 页面显示该格式与当前 scope 或月份暂无排位记录，不伪造零分玩家，也不展示上一笔查询数据

#### Scenario: 排行榜请求失败

- **WHEN** 排行榜 API 返回错误或网络请求失败
- **THEN** 页面清除过期排行内容，显示可理解的加载失败提示并提供重新请求当前选择的操作

#### Scenario: 昵称包含 HTML 字符

- **WHEN** API 返回的昵称包含 `<`、`>`、`&` 或类似可组成标记的字符
- **THEN** 页面按原昵称文本显示这些字符，不创建或执行昵称中的 HTML、脚本或事件处理器

### Requirement: 页面布局适配常见浏览器宽度

页面必须（MUST）在桌面与窄屏浏览器中保持格式、榜单切换、月份控件和排行字段可访问；窄屏不得（SHALL NOT）因表格宽度裁掉无法访问的列。

#### Scenario: 窄屏查看排行榜

- **WHEN** 用户在宽度不超过 480 像素的视口打开有数据的排行榜
- **THEN** 用户仍能访问排名、昵称、积分、胜场和负场全部字段，并能切换总榜、月榜和月份

### Requirement: 后续格式复用同一页面能力

页面不得（SHALL NOT）为 1103 与 1109 复制格式专用实现。以后通过固定格式注册表显式启用的新格式必须（MUST）能够复用同一路径、页面结构和 API 参数。

#### Scenario: 访问以后启用的格式

- **WHEN** 后端显式注册一个新固定格式且其排行榜 API 已可用，用户访问 `/leaderboards/<新格式>`
- **THEN** 服务器使用同一页面能力展示该格式，所有请求保持该格式隔离，不需要新增格式专用页面
