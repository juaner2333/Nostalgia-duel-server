## Purpose

向玩家公开展示 1103 与 1109 各自当前及历史自然半年度的卡组和卡片使用率，并以固定边界、实际截止日、样本总数、Side 已知样本数和更新时间说明数据含义与新鲜度；缺失可信快照的比赛不进入使用率分母。

## ADDED Requirements

### Requirement: 提供双环境公开使用率页面

系统必须（MUST）在 `/leaderboards/:format/usage` 为 1103 与 1109 提供无需登录的使用率页面，并从对应环境现有决斗专区提供入口。页面必须（MUST）包含卡组、怪兽、魔法、陷阱、额外卡组及 Side 六个可切换榜单，以及当前和已发布历史半年度选择器；环境、半年度和当前指标必须（MUST）能从 URL 明确识别。页面不得（MUST NOT）混用另一环境或另一半年度的统计结果；切换半年度时必须（MUST）回到第一页。

#### Scenario: 从决斗专区进入页面

- **WHEN** 用户在 1103 决斗专区打开使用率入口
- **THEN** 用户进入 1103 使用率页面，可切换六个榜单，且不看到 1109 的计数

#### Scenario: 1103 卡组标签

- **WHEN** 用户查看有样本的 1103 卡组使用率榜
- **THEN** 页面仅展示现有分类的“其他”，不虚构参考站的具名分类

#### Scenario: 切换历史半年度

- **WHEN** 用户从 1109 的 `2026H2` 切换到已发布的 `2026H1`
- **THEN** 页面仅展示 `[2026-01-01, 2026-07-01)` 的统计结果，并在 URL 保留 `period=2026H1`、将页码设为 1

### Requirement: 提供只读聚合查询接口

系统必须（MUST）提供公开的 `GET /api/ladder/:format/usage`，以 `metric=deck|monster|spell|trap|extra|side` 选择榜单，可选 `period=YYYYH1|YYYYH2` 选择已发布的自然半年（省略时为北京时间当前半年），并支持正整数 `page` 与 `pageSize`（默认 1、50，每页最多 100）。另提供 `GET /api/ladder/:format/usage/periods`，按时间倒序返回该环境已发布的半年标识及其固定边界和实际统计截止日。榜单响应必须（MUST）返回环境、指标、半年度标识、窗口开始与固定结束边界（结束不包含）、实际统计截止日（不包含）、时区、成功发布时间、`totalDecks`、`sideKnownDecks`、当前榜单分母、总条数和当前页。卡组行必须（MUST）提供类别代码、名称、使用数及 0–1 使用率；卡片行必须（MUST）提供归一卡片 ID、固定资源中的名称、使用卡组数、0–1 使用率和投入 1/2/3 张的数量。计数为零的分母对应使用率必须（MUST）为 `null`。

#### Scenario: 查询 Side 使用率

- **WHEN** 客户端请求 1109 的 `metric=side` 第一页
- **THEN** 响应的分母等于 `sideKnownDecks`，卡片行包含 Side 内的采用量和 1/2/3 张分布

#### Scenario: 查询卡组使用率

- **WHEN** 客户端请求 1109 的 `metric=deck`
- **THEN** 响应按 1109 类别返回计数，包含“其他”，且分母等于 `totalDecks`

#### Scenario: 历史半年只使用自身样本

- **WHEN** 客户端请求 `period=2026H1&metric=monster`，且 2026 年 7 月 1 日存在同一卡片的使用记录
- **THEN** 响应只依据 2026 年 1 月 1 日至 7 月 1 日前的有效快照计算，7 月 1 日记录不增加任何计数或分母

### Requirement: 排名与分页稳定且可复算

接口必须（MUST）按使用数降序排列；数量相同的卡片按归一 ID 升序、卡组按环境内类别代码升序排列。`rank` 必须（MUST）是完整榜单中的名次，而不是每页从 1 重新开始。`usageRate` 必须（MUST）由响应中的原始计数和当前榜单分母计算，不得（MUST NOT）对已四舍五入的百分比再次求平均。页面必须（MUST）将使用率显示为百分比，并让用户分页查看完整榜单。

#### Scenario: 并列数量跨页

- **WHEN** 两张使用数相同的卡片位于分页边界
- **THEN** 它们按卡片 ID 稳定排序，前后页无重复或遗漏，名次延续完整榜单顺序

### Requirement: 明示样本、窗口与数据新鲜度

页面必须（MUST）展示所选半年度的固定日期范围、实际统计截止日、最近一次成功更新时间、`totalDecks` 和当前指标的分母；Side 页还必须（MUST）展示 `sideKnownDecks` 并说明它只是总样本的子集。查看当前半年度时，若实际统计截止日早于当前北京时间自然日开始，页面必须（MUST）明确标为旧数据；查看已结束半年度时，若实际统计截止日早于其固定结束边界，页面必须（MUST）明确标为尚未最终补齐。刷新页面不得（MUST NOT）触发在线全量重算。

#### Scenario: 定时任务失败后查看页面

- **WHEN** 当天任务失败但前一天结果仍可用
- **THEN** 页面继续展示该半年度前一天完整结果、固定边界、实际截止日与更新时间，并提示数据未更新到今天

#### Scenario: Side 覆盖低于主卡组

- **WHEN** 历史回填使 `sideKnownDecks` 小于 `totalDecks`
- **THEN** Side 页面显示 Side 的有效样本数，不把缺失 Side 展示为未投入任何卡

### Requirement: 无效请求与未生成数据有明确结果

接口对不支持的环境必须（MUST）返回 404，对无效半年标识、指标、页码或页大小必须（MUST）返回 400；排位统计关闭、该环境尚无任何成功汇总或指定半年度尚未发布时必须（MUST）返回明确的不可用状态。页面必须（MUST）区分“已成功统计但该半年无样本”和“该半年统计尚未生成或读取失败”。公开响应不得（MUST NOT）包含玩家 ID、个人卡组清单或录像二进制。

#### Scenario: 空样本与未生成汇总

- **WHEN** 某环境已成功发布零样本汇总，而另一环境从未成功运行任务
- **THEN** 前者返回带两个零样本计数的空榜单，后者返回统计未就绪，不把两种状态混淆

#### Scenario: 非法指标

- **WHEN** 客户端请求 `metric=unknown`
- **THEN** 接口返回 400，且不查询或修改统计结果
