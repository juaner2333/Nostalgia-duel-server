## Purpose

向玩家公开展示 1103 与 1109 各自最近一次成功生成的滚动 90 天卡组及卡片使用率，并以窗口、覆盖率和更新时间说明数据含义与新鲜度，避免把缺失快照解释为未使用。

## ADDED Requirements

### Requirement: 提供双环境公开使用率页面

系统必须（MUST）在 `/leaderboards/:format/usage` 为 1103 与 1109 提供无需登录的使用率页面，并从对应环境现有决斗专区提供入口。页面必须（MUST）包含卡组、怪兽、魔法、陷阱、额外卡组及 Side 六个可切换榜单；环境和当前指标必须（MUST）能从 URL 明确识别。页面不得（MUST NOT）混用另一环境的统计结果。

#### Scenario: 从决斗专区进入页面

- **WHEN** 用户在 1103 决斗专区打开使用率入口
- **THEN** 用户进入 1103 使用率页面，可切换六个榜单，且不看到 1109 的计数

#### Scenario: 1103 卡组标签

- **WHEN** 用户查看有样本的 1103 卡组使用率榜
- **THEN** 页面仅展示现有分类的“其他”，不虚构参考站的具名分类

### Requirement: 提供只读聚合查询接口

系统必须（MUST）提供公开的 `GET /api/ladder/:format/usage`，以 `metric=deck|monster|spell|trap|extra|side` 选择榜单，并支持正整数 `page` 与 `pageSize`（默认 1、50，每页最多 100）。响应必须（MUST）返回环境、指标、窗口开始与结束（结束不包含）、时区、成功发布时间、`allDecks`、`validDecks`、`sideKnownDecks`、当前榜单分母、总条数和当前页。卡组行必须（MUST）提供类别代码、名称、使用数及 0–1 使用率；卡片行必须（MUST）提供归一卡片 ID、固定资源中的名称、使用卡组数、0–1 使用率和投入 1/2/3 张的数量。计数为零的分母对应使用率必须（MUST）为 `null`。

#### Scenario: 查询 Side 使用率

- **WHEN** 客户端请求 1109 的 `metric=side` 第一页
- **THEN** 响应的分母等于 `sideKnownDecks`，卡片行包含 Side 内的采用量和 1/2/3 张分布

#### Scenario: 查询卡组使用率

- **WHEN** 客户端请求 1109 的 `metric=deck`
- **THEN** 响应按 1109 类别返回计数，包含“其他”，且分母等于 `validDecks`

### Requirement: 排名与分页稳定且可复算

接口必须（MUST）按使用数降序排列；数量相同的卡片按归一 ID 升序、卡组按环境内类别代码升序排列。`rank` 必须（MUST）是完整榜单中的名次，而不是每页从 1 重新开始。`usageRate` 必须（MUST）由响应中的原始计数和当前榜单分母计算，不得（MUST NOT）对已四舍五入的百分比再次求平均。页面必须（MUST）将使用率显示为百分比，并让用户分页查看完整榜单。

#### Scenario: 并列数量跨页

- **WHEN** 两张使用数相同的卡片位于分页边界
- **THEN** 它们按卡片 ID 稳定排序，前后页无重复或遗漏，名次延续完整榜单顺序

### Requirement: 明示覆盖、窗口与数据新鲜度

页面必须（MUST）展示实际统计的 90 天日期范围、最近一次成功更新时间，以及候选样本和当前指标有效样本的覆盖关系。若最近一次成功结果的窗口结束时间早于当前北京时间自然日开始，页面必须（MUST）明确标为旧数据，不能（MUST NOT）将其标作最新 90 天；刷新页面不得（MUST NOT）触发在线全量重算。

#### Scenario: 定时任务失败后查看页面

- **WHEN** 当天任务失败但前一天结果仍可用
- **THEN** 页面继续展示前一天完整结果、其真实窗口与更新时间，并提示数据未更新到今天

#### Scenario: Side 覆盖低于主卡组

- **WHEN** 历史回填使 `sideKnownDecks` 小于 `validDecks`
- **THEN** Side 页面显示 Side 的有效样本数，不把缺失 Side 展示为未投入任何卡

### Requirement: 无效请求与未生成数据有明确结果

接口对不支持的环境必须（MUST）返回 404，对无效指标、页码或页大小必须（MUST）返回 400；排位统计关闭或该环境尚无任何成功汇总时必须（MUST）返回明确的不可用状态。页面必须（MUST）区分“已成功统计但窗口无样本”和“统计尚未生成或读取失败”。公开响应不得（MUST NOT）包含玩家 ID、个人卡组清单或录像二进制。

#### Scenario: 空样本与未生成汇总

- **WHEN** 某环境已成功发布零样本汇总，而另一环境从未成功运行任务
- **THEN** 前者返回带零覆盖的空榜单，后者返回统计未就绪，不把两种状态混淆

#### Scenario: 非法指标

- **WHEN** 客户端请求 `metric=unknown`
- **THEN** 接口返回 400，且不查询或修改统计结果
