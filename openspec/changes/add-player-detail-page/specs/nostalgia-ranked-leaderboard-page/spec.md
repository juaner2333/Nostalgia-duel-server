## ADDED Requirements

### Requirement: 玩家详情入口保留环境与昵称保护

天梯与录像页面必须（MUST）将可见的真实玩家昵称链接到当前格式的玩家详情页。天梯入口必须（MUST）保留所选总战绩或半年赛季范围用于战绩摘要及卡组统计，录像入口的统计范围必须（MUST）默认使用当前半年；对战记录和积分曲线必须（MUST）统一展示当前环境全时期最近二十场。两种入口均必须（MUST）从公开状态和第 1 页开始，不携带凭据或内部账号 ID。天梯中按现有规则显示为 `******` 的昵称必须（MUST）继续打码，不能（MUST NOT）通过链接、DOM 属性、标题或页面新状态暴露被隐藏的昵称或详情网址；有搜索词而显示真实昵称时必须（MUST）允许进入详情。新增入口必须（MUST）保持原有天梯搜索、分页、录像和卡组下载操作。

#### Scenario: 天梯可见昵称进入历史赛季详情

- **WHEN** 用户在 1109 的 `2026H1` 天梯点击可见玩家昵称
- **THEN** 打开该昵称的 1109 详情，战绩与卡组统计选择 `2026H1`，对战记录及曲线仍使用全时期最近二十场，第 1 页且处于公开状态

#### Scenario: 总榜入口保留总战绩范围

- **WHEN** 用户在 1103 总榜点击可见玩家昵称
- **THEN** 打开该昵称在 1103 的总战绩详情，不携带赛季参数

#### Scenario: 后段打码玩家不产生隐藏链接

- **WHEN** 天梯没有搜索词且某玩家符合后 30% 打码规则
- **THEN** 该行仍显示 `******`，无可暴露真实昵称或详情网址的新链接、标题及 DOM 属性

#### Scenario: 搜索后的真实昵称可以进入详情

- **WHEN** 用户搜索后看到真实昵称并点击
- **THEN** 进入当前环境与范围的对应玩家详情，不改变原有搜索和分页规则

#### Scenario: 录像入口保留环境和原有下载

- **WHEN** 用户在 1103 录像列表点击任一方的可见昵称
- **THEN** 进入 1103 当前半年赛季的对应玩家详情，原有 YRP 和双方 YDK 下载仍可独立使用
