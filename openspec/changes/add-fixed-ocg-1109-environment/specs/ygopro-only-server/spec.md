## MODIFIED Requirements

### Requirement: 仅部署 YGOPro 资源集

已部署的资源集必须（SHALL）仅包含显式启用的固定 YGOPro 怀旧环境所需卡片数据库、脚本、禁限卡表和 WASM 决斗核心，并且不得（SHALL NOT）包含组装后的 `edopro` 资源树、未启用 YGOPro 赛制资源或扩展卡池。本次启用集合必须（SHALL）仅为 OCG 2011.03（1103）与 OCG 2011.09（1109）。

#### Scenario: 资源完成组装

- **WHEN** 从干净检出组装生产资源版本
- **THEN** 发布版本包含固定 `706-cards.cdb`、固定基础脚本、1103/1109 禁限卡表、各自可选覆盖脚本和 YGOPro 决斗核心，且不包含 `edopro` 目录或未启用赛制资源

#### Scenario: 保留所需的上游禁限卡表数据

- **WHEN** 迁移前的上游资源源包含 2011.03 或 2011.09 限制数据，同时还供给将被删除的赛制
- **THEN** 系统将已审核的 OCG 2011.03 与 OCG 2011.09 限制输入固化为本地文件并生成两份白名单，之后删除该上游依赖且不丢失任一环境规则

#### Scenario: 双用途禁限卡表源保留 YGOPro 文件

- **WHEN** 原双用途禁限卡表源的其他消费者全部移除
- **THEN** 系统仅把 1103 与 1109 所需规则迁移为带摘要的本地固定文件，不再保留该双用途 source、其仓库缓存或其他赛制文件

#### Scenario: 移除无关上游资源

- **WHEN** 检查生效的资源清单、仓库缓存和发布树
- **THEN** 不存在仅供已移除的 MD、Tengu、HAT、Edison、JTP、World、Genesys、Rush、Speed、GOAT、通用现代 OCG、预发布或自定义卡环境使用的资源源、组装目标或缓存

#### Scenario: 后续增加其他怀旧环境

- **WHEN** 后续变更显式启用 1103 与 1109 之外的新环境
- **THEN** 该环境必须提供自己的卡池派生规则、禁限卡表和可选脚本覆盖，并通过同一固定资源完整性门禁后才进入发布树

### Requirement: 资源刷新排除 EDOPro 数据

资源发布和任何保留的刷新流程必须（SHALL）避免拉取、复制、计算指纹或保留 EDOPro 数据以及未启用 YGOPro 赛制数据。固定 1103/1109 卡池、脚本和禁限卡表不得（SHALL NOT）跟随浮动上游分支更新；资源内容只能通过经过审核并产生新锁定摘要的应用发布变更。

#### Scenario: 定时刷新完成

- **WHEN** 已部署服务经过原定资源刷新周期或重启
- **THEN** 1103 与 1109 的活动卡池、脚本和禁限卡表摘要保持不变，不创建外部仓库缓存，也不重新引入未启用赛制或 EDOPro 数据

#### Scenario: 审核后升级固定资源

- **WHEN** 运维部署一份包含新资源锁文件且通过全部完整性校验的应用版本
- **THEN** 系统原子发布包含 1103 与 1109 的新固定资源版本，并保留上一版本作为失败回滚边界
