## ADDED Requirements

### Requirement: 具名卡组使用率行提供半年详情入口

使用率页面必须（MUST）为当前环境具名卡组名称增加 `/leaderboards/:format/deck-detail?deckTypeCode=<代码>&period=<当前所选半年>` 链接，包含前 16 名以外的类型；“其他”及未知不得（MUST NOT）提供此入口。原使用率页面和 API 必须（MUST）继续展示其已有“其他”行，保持原总样本分母、计数、分页、卡片榜单及每日发布行为，不得（MUST NOT）因详情排除其他而改写原榜。详情入口必须（MUST）保留环境和半年，名称按文本渲染且参数编码。

#### Scenario: 从榜单进入名单外卡组详情

- **WHEN** 用户在 1109 使用率榜的 2026H1 页面点击排名第 17 的具名卡组 A
- **THEN** 进入 A 的 1109、2026H1 详情，不切换为当前半年或要求其入选矩阵

#### Scenario: 其他行保持原行为

- **WHEN** 用户查看原使用率榜中的“其他”行或 1103 榜单
- **THEN** 原行及其计数仍显示，但无卡组详情链接，其他榜单和分页不受影响
