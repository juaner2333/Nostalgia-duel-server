## Why

当前服务已有 1109 排位卡组分类与半年度使用率，但没有按卡组对阵、G1 先后攻拆分的 Match 胜率。玩家需要与半年度赛季同步、每天更新的前 16 类卡组对阵矩阵，且不让“其他”或名单外对局稀释矩阵中的胜率。

## What Changes

- 为 1109 排位新增北京时间自然半年 `YYYYH1|YYYYH2` 的卡组 Match 对阵汇总；现有半年度使用率任务改在每天 03:00 启动，并在同一批次重建当前半年的使用量与对阵。换期时补齐上半年最终结果，沿用指定历史半年重建能力。
- 按同一统计窗口内可信初始卡组的使用份数选出前 16 个具名类型；相同份数按卡组代码稳定排序。仅把双方均属于这 16 类、G1 座次可信且结果有效的物理 Match 计入矩阵。“其他”和名单外类别均不进入矩阵单元与汇总分母。
- 新增名为「卡组胜率」的页面，在 1109 决斗专区顶栏与「房间列表」「录像下载」「天梯排行」「使用率」并列；只提供 Match 综合、Match 先攻和 Match 后攻三个视图，公开半年度切换、原始胜场/场数、入选对阵场数与更新时间。参考站仅作矩阵交互参考，不作为数据源或分类规则来源。
- 为新结算补充可追溯的小局编号与先后攻事实；历史记录从真实录像分别核验并回填编号与座次，未知座次的 G1 明确排除。汇总在后台原子发布，查询不扫描原始比赛。

## Capabilities

### New Capabilities

- `nostalgia-half-year-deck-winrate-matrix`: 定义半年度窗口、前 16 名筛选、有效 Match 与先后攻胜率口径、每日重建、公开 API 和矩阵页面。

### Modified Capabilities

无。现有使用率榜单、天梯积分与赛季归属规则不改变。

## Impact

- 数据：`duels` 增加可空的小局编号与座次事实；沿用现有 `usage_stat_runs` 和 `usage_deck_rows`，仅新建一张半年度物理 Match 对阵表，不重复存储 Match 总数。
- 服务：扩展现有半年度重建任务，使 1109 使用量与对阵原子发布；新增只读聚合 API 和 1109 决斗专区顶栏「卡组胜率」Tab，继续使用排位开关与公开接口限流。
- 运维：把现有 03:10 使用率任务调整为北京时间 03:00 的唯一计划任务；无需第二条矩阵 crontab。
