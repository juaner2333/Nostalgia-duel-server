## Purpose

为各已启用环境的排位 Match 留下一份可信的双方初始卡组事实，使同一场比赛的每条录像都能展示正确类型并导出同一副可验证的卡组，同时明确历史录像无法恢复的 Side 数据。

## ADDED Requirements

### Requirement: 在 G1 前冻结双方初始卡组

各已启用环境的排位 Match 必须（MUST）在 G1 开始前，从双方已通过该环境固定卡池与禁限卡表校验的卡组各冻结一份初始快照。每份快照必须（MUST）保留 Main、Extra、Side 中每张卡的原始卡片 ID 和重复张数；用于分类的别名归一结果不得（MUST NOT）覆盖导出用原始 ID。G2/G3 换 Side 或重连后的卡组提交不得（MUST NOT）改变该初始快照。

#### Scenario: 冻结通过校验的两副卡组

- **WHEN** 两名 1103 或 1109 排位玩家均通过对应环境的卡组校验并准备开始 G1
- **THEN** 系统为各玩家保留其 G1 前的 Main、Extra、Side 原始卡片 ID 与重复张数，供整场 Match 结算使用

#### Scenario: 换备不改变初始快照

- **WHEN** G1 结束后玩家在 G2 或 G3 前换入 Side 卡
- **THEN** 该 Match 的初始快照仍是 G1 前卡组，后续小局的录像卡组下载仍指向该快照

### Requirement: 只在整场 Match 结算后保存快照

冻结中的快照必须（MUST）只存在于未结算 Match 的运行状态中。仅当已启用环境的排位 Match 进入正式终结流程并产生有效玩家视角比赛记录后，系统才必须（MUST）把对应初始快照与比赛、小局、录像和排位结算数据在同一原子批次保存；每条玩家视角 Match 记录至多对应一份快照。快照的 `format_id` 必须（MUST）与所属 `matches.format_id` 及所引用 `deck_types.format_id` 一致。重复终结通知或重试不得（MUST NOT）生成重复快照，也不得（MUST NOT）把单方快照或无主快照留在数据库中。

#### Scenario: G1 结束但 Match 仍在进行

- **WHEN** G1 正常结束且 Match 进入换备阶段
- **THEN** 数据库中尚无该 Match 的卡组快照，现有比赛、小局和录像持久化时机也保持在整场结算之后

#### Scenario: 有效 Match 完成

- **WHEN** 双方记录完整的 1103 或 1109 排位 Match 正式结算
- **THEN** 双方各自的初始快照与该 Match 的比赛、小局、录像及排位结算数据一起提交，每位玩家视角恰好一份

#### Scenario: 保存失败与重复终结

- **WHEN** 结算事务任一步失败，或同一 Match 的终结通知被重复处理
- **THEN** 失败事务不留下部分卡组快照，重试成功后同一玩家视角仍只有一份快照且积分与录像不重复

#### Scenario: 未形成有效排位比赛

- **WHEN** 排位房未形成有效玩家视角 Match 记录就终结
- **THEN** 系统不保存与该场比赛无关或无法关联的卡组快照

### Requirement: 同一 Match 的各小局复用初始快照

卡组快照的身份必须（MUST）由玩家视角 Match 决定。同一 Match 内实际存在的 G1、G2、G3 录像必须（MUST）分别关联回相同的两份初始快照；不得（MUST NOT）按小局复制快照，也不得（MUST NOT）把 G2/G3 当局换备后的 Main 或 Side 标记为“初始卡组”。

#### Scenario: 三局比赛的录像关联

- **WHEN** 一场 1103 或 1109 排位 Match 实际产生 G1、G2、G3 三条录像
- **THEN** 三条录像各自都能关联到同一对玩家视角初始快照，同一玩家在三条录像中得到相同的初始卡组内容

### Requirement: 历史快照只回填可信内容

对于本能力上线前已完成的 1103 和 1109 排位 Match，系统必须（MUST）仅在 G1 原始录像可解析、两位玩家与有效比赛记录可无歧义配对、卡片 ID 和卡组规模可由对应环境固定资源验证时，回填双方的原始 Main 与 Extra。历史 G1 录像没有可靠的原始 Side 时，快照必须（MUST）明确标记 Side 未知，不能（MUST NOT）用空 Side 或 G2/G3 的换备推算值冒充完整初始卡组。回填时必须（MUST）按 Match 环境分类；1103 的可信快照归为 OTHERS。回填不得（MUST NOT）覆盖已有的完整在线快照。

#### Scenario: 可信历史 G1 录像

- **WHEN** 历史 1103 或 1109 排位 Match 的 G1 录像和双方身份均验证成功
- **THEN** 系统可为双方建立 Main、Extra 可信而 Side 未知的部分快照，并保留录像中的原始卡片 ID

#### Scenario: 历史 G1 缺失或身份歧义

- **WHEN** G1 录像缺失、损坏、不是双人录像，或无法将录像中的两副卡组唯一对应到双方比赛记录
- **THEN** 系统不为受影响玩家猜测或伪造快照，后续列表将其类型视为未知

#### Scenario: 已有完整在线快照

- **WHEN** 历史回填再次遇到同一玩家视角且该视角已有完整在线快照
- **THEN** 已保存的 Main、Extra、Side 与分类版本保持不变

### Requirement: 范围仅限已启用环境的排位

该快照能力必须（MUST）处理当前固定环境 1103 与 1109 的排位 Match，并按环境选择校验资源与分类器。以后新增已启用环境时必须（MUST）沿用相同的 Match 快照流程；普通数字房、未启用环境与无效比赛不得（MUST NOT）因本能力新增卡组快照写入。

#### Scenario: 其他房间完成决斗

- **WHEN** 任一环境的非排位房或未启用环境完成对局
- **THEN** 本能力不创建该对局的卡组快照
