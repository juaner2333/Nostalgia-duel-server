### 验证方式

- **覆盖清单**（`historical-rulings/coverage.test.ts`）：12 个 ID 在两个 format 目录逐一存在且逐文件 SHA-256 一致；全部存在于固定 base CDB 与两份白名单；format 隔离（带标记临时脚本不跨 format 读取）。
- **聚焦 WASM 场景**（`historical-rulings/batch1.test.ts`、`necrovalley.test.ts`）：使用固定 CDB、format-first 脚本链与真实 `koishipro-core.js` ocgcore，断言可观察消息/卡片状态；全部在现代 base 上先失败、在覆盖脚本上通过。
- **资源完整性**：`npm run check:nostalgia-resources` 通过；`npm run smoke:duel` 双环境建房、卡组校验、真实 WASM 决斗与观战通过。
